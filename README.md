# Табло ATP и WTA

Календарь мужского и женского тура 2026, сетки текущих турниров и расписание матчей с временем в часовом поясе зрителя.

- `index.html` — приложение (одна страница, работает и без интернета после первого открытия);
- `data/tablo.json` — данные: календари (`seasons.atp`, `seasons.wta`) и сетки турниров (`draws`);
- `manifest.webmanifest`, `sw.js`, `icons/` — установка на телефон и компьютер.

Данные обновляются раз в день автоматически: запланированная задача в Claude собирает свежие результаты и записывает `data/tablo.json` в этот репозиторий.
